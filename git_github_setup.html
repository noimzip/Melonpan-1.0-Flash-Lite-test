Introduction

Git と GitHub の違い

Git

Git PCの中で動く

あなたのパソコンの中で、ファイルの変更履歴を細かく記録する「超高性能なカメラ」です。何か間違えても、過去の写真（コミット）にいつでも巻き戻せます。

Hub

GitHub ネット上のサービス

ネット上にある、みんなで写真（Gitの履歴）を保管・公開する「巨大な美術館」です。ここに作品を預けることで、全世界へ公開したり、仲間と共同開発できます。

💡 POINT: 手元のPCで「Git」を使い歴史を作り、それを「GitHub」へ送る（プッシュする）ことで公開します。
Step 1 (Part 1/2)

GitHub アカウントの作成：スタート

まずは、ネット上の美術館（GitHub）のアカウントを非常に丁寧に作成していきます。

1

公式サイトにアクセスする

ブラウザで github.com にアクセスします。

2

「Sign up」ボタンをクリック

画面の右上、または中央にある、オレンジや白、緑で目立つ Sign up for GitHub ボタンを押します。

3

SFのような演出に合わせて情報を入力する

宇宙のような背景の中、チャット形式で順番に尋ねられます：

  • Email address: 普段使っているメールアドレスを入力 ➔ Continue
  • Password: 強固なパスワード（英数字、記号）を設定 ➔ Continue
  • Username: 希望するユーザー名（半角英数字と一部の記号のみ）を入力 ➔ Continue
⚠️ 注意: ユーザー名（Username）は、あなたのGitHubのURL（例: github.com/ユーザー名）になるため、本名や恥ずかしくない簡潔な英語がおすすめです。
Step 1 (Part 2/2)

GitHub アカウントの作成：完了

入力を進めて、アカウント作成プロセスを最後まで完了させます。

4

Email Preferences (お知らせ配信の可否)

「GitHubからニュースや更新情報を受け取りますか？」と聞かれます。不要なら「n」、受け取るなら「y」と入力して Continue をクリックします。

5

Spam Verification (パズルの突破)

「あなたがロボットでないことを証明してください」とパズル（同じ絵柄を選ぶなど）が出題されるので、指示通りにクリアします。

6

認証コードの入力 ➔ 完了！

登録したメールアドレス宛に 8桁のワンタイムコード が届きます。それをブラウザの画面に入力すれば、無事にアカウント作成は完了です！

成功: これで「ネット上の美術館（GitHub）」にあなただけの展示スペースが確保されました！
Step 2 (Part 1/2)

WindowsにGitを入れよう（入手編）

次に、手元のPCに歴史を保存するカメラ（Git本体）をダウンロードします。

GIT FOR WINDOWS OFFICIAL Git for Windows
公式サイトへアクセス

ダウンロード手順

  1. 上記公式サイトを開き、目立つ「Download」ボタンをクリックします。
  2. お使いのPCに適したインストーラ（通常は 64-bit Git for Windows Setup）のダウンロードが自動で始まります。
  3. ダウンロードされたファイル（例：Git-2.xx.x-64-bit.exe）を確認します。
💡 豆知識: Windows用のGitには、超初心者がもっとも助けられるツール「Git Bash（擬似的なコマンドライン端末）」が最初から同梱されています。
Step 2 (Part 2/2)

WindowsにGitを入れよう（インストール編）

インストーラを動かしてPCに導入します。迷いがちな設定について。

不安を解消：基本は全て「Next」連打でOK！ 設定項目が10画面以上現れ、英語で色々と聞かれますが、現在、Gitの初期値（デフォルト設定）は十分に洗練されています。すべて Next > を押し続ければ最良の構成になります。

💡 念のため確認しておくと良いチェックポイント：

デフォルトのエディタ設定 「Choosing the default editor used by Git」では、初期のまま（Vimなど）か、お使いの VS Code などへ安全に変更可能です。
フォルダ内の改行コード自動変換 「Configuring the line ending conversions」では、最も推奨される Checkout Windows-style, commit Unix-style line endings が選ばれていることを確認。
🎉 インストールが完了したら、スタートメニューに「Git Bash」というアプリが入っていることを確認してください。
Step 3

手元PCの初期設定（名前とメアド登録）

インストールした「Git Bash」を起動し、歴史を記録する際の署名（あなたの名前とアドレス）を一度だけ登録します。

$ git config --global user.name "YourName"
$ git config --global user.email "your_email@example.com"
💡 ヒント: "YourName" や "your_email@example.com" は、ご自身の情報（名前は半角ローマ字推奨、メアドはGitHub登録で使用したもの）に書き換えて実行してください。
※ この設定を行わないと、今後ファイルのコミット（記録）をする際に「君は誰？」とGitから叱られてしまいます。
Step 4 (Part 1/4)

SSHキーってなに？（やさしい図解）

手元PCからGitHubへ安全に作品を運ぶための「秘密の合い鍵」の概念を解説します。

🔑

秘密鍵（プライベートキー）

id_ed25519

あなた自身のPCから絶対に持ち出してはいけない物理的なカギ。誰にも見せてはいけません。

🔒

公開鍵（パブリックキー）

id_ed25519.pub

GitHubに設置するデジタルな電子ロック（鍵穴）。誰に見られても全く問題ありません。

「手元の秘密鍵」と「GitHubに登録した公開鍵」がピッタリ合致した時だけ、パスワードなしで一瞬で安全に通信が行えます。
💡 安心： この設定を終えれば、毎回ログインパスワードを打ち込む面倒から永久に解放されます。
Step 4 (Part 2/4)

SSHキーを作成する（Git Bashにて）

Git Bashを使って、PCの中に最先端の安全な鍵（ed25519暗号）を作成しましょう。

$ ssh-keygen -t ed25519 -C "your_email@example.com"

実行中に聞かれること（迷いやすい3ステップ）：

1. Enter file in which to save the key... ➔ 鍵の保存先を聞かれます。何も書かずに「Enterキー」を押します。
2. Enter passphrase... ➔ 鍵用の追加暗号コード。基本は何も入力せずに「Enterキー」でOKです。
3. Enter same passphrase again... ➔ 確認のため、もう一度「Enterキー」を押します。
🎉 画面にアスキーアート（記号の絵）が現れれば、あなたのPC内に最強の鍵ペア（秘密鍵と公開鍵）が無事に生成されました！
Step 4 (Part 3/4)

公開鍵をGitHubに登録する

作った「鍵穴（公開鍵）」をコピーして、GitHubに設置しましょう。

$ clip < ~/.ssh/id_ed25519.pub

GitHubの登録手順

  1. 上記のコピーコマンドを実行します（一瞬で公開鍵がコピーされます）。
  2. GitHubを開き、右上の「自分のアイコン」 ➔ Settings を開きます。
  3. 左側メニューの「SSH and GPG keys」を選択します。
  4. 「New SSH key」ボタン（緑色）をクリック。
  5. Title: には何のPCの鍵かわかる名前（例: My Windows PC）を入力。
  6. Key: の入力エリアに、キーボードの Ctrl + V を押して貼り付けます。
  7. 緑色の「Add SSH key」ボタンをクリック！
⚠️ 注意： 貼り付けるキーは ssh-ed25519 ... で始まる文字列です。絶対に間違えないようにしましょう。
Step 4 (Part 4/4)

繋がったかテストしてみよう！

全ての準備が整いました。手元のPCからGitHubに正常にアクセスできるかを検証します。

$ ssh -T git@github.com

⚠️ 初回接続時のみ表示される警告メッセージ：

「接続先の正真性が確認できませんが、続行しますか？」と聞かれます。

Are you sure you want to continue connecting (yes/no/[fingerprint])?

ひるまずに 「yes」と入力 して Enter を押してください。

🎉 以下のメッセージが出れば大成功です！ Hi [Your Username]! You've successfully authenticated...
「無事に認証に成功しました。ただしシェルアクセスは提供していません」という意味なので、大成功です！
